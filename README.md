## proyecto pdf-extractect
Extraer texto de un PDF proporcionado por el usuario. Hacer un resumen de dicho texto utilizando modelo IA.

## tecnologias

* Python
* UV 
* Modelo IA
* Base de datos no relacional MongoDB
